# Neighborhood-Preserving-Voronoi-Treemaps

## About

Neighborhood Preserving Voronoi Treemaps is an adaption of traditional weighted Voronoi treemaps.  
The goal of the techinque is to preserve existing similarities within the data as neighborhood in the Voronoi treemap.
In this repository you will find a link to the current, preliminary tool, and apreliminary version of the code. 
A more polished version will be released upon publication.  

# Online Tool

We are hosting preliminary version of the tool at [https://voronoitreemap.de](https://voronoitreemap.de).
